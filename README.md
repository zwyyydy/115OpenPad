# 115 OpenPad

基于 [115 生活开放平台 API](https://www.yuque.com/115yun/open) 开发的第三方 115 网盘客户端，专为 **Android 平板与手机**设计。

## 功能

- **登录**：扫码授权 / 免 AppID 导入 Token，令牌自动续期
- **文件浏览**：列表 / 网格、分类筛选、星标、搜索、面包屑、多选批量操作（移动 / 复制 / 重命名 / 星标 / 删除 / 下载）
  - 文件夹置顶（只存本机）、快捷目录收藏、按目录记忆滚动位置、60 秒目录缓存、文本预览
- **媒体库（海报墙）**：扫描网盘的影视目录建成本地索引，海报墙 → 详情页（简介 / 演员 / 标签 / 剧照 / 技术参数），剧集自动分层成一张系列卡
  - 读同目录的 `.nfo`（47 个字段）与 `poster / fanart / thumb / extrafanart / .actors` 素材；演员、标签可点，跨库看同演员 / 同标签作品
  - 增量扫描（按目录指纹）、每库自动扫描间隔、扫描可停止、扫描记录、观影历史与续播
  - 排序 9 档 + 筛选（年份 / 演员 / 类型·标签）+ 随机播放、全局搜索、海报与简介落盘缓存、条目移除 / 彻底删除
- **批量重命名**：查找替换（7 种选段）/ 插入 / 自动编号 / 手动编辑，逐行预览；后台队列顺序执行、限速可调，关页面与退出应用都不中断
- **图片浏览**：大图画廊（翻页 / 预取 / 缩放 / 下拉关闭）、超大图分块解码不 OOM、鸟瞰位置图；浏览过的图落盘缓存，重进不再重下
- **视频播放器**（Media3 ExoPlayer）
  - HLS 流式播放 + 本次播放内缓存（退出即清）、清晰度切换（含「原盘」）、多音轨、在线字幕搜索与字号 / 位置调节
  - 手势：双击快进 / 快退、左右滑调亮度 / 音量、横滑非线性快进、0.5x~4x 长按倍速
  - 画面 90° 旋转、HDR 转 SDR、软 / 硬解就地切换、截图存相册
  - **VR 观看**：180°/360° 实时反投影，竖屏视窗档位（满屏 / 3:4 / 1:1）可选
  - **实验室 · 视频滤镜**（默认关）：8 预设 + 亮度 / 对比度 / 饱和度 / 色温 / 磨皮 / 暗角，参数全局记住
  - 播放列表抽屉、屏幕锁、缓冲动效、右上角状态栏（时钟 / 电量 / 网速 / 画质规格）
  - 已下载文件用应用内播放器打开；其他应用「打开 / 分享视频」可唤起本应用
- **云下载**：磁力 / 电驴 / HTTP(S) / FTP，`.torrent` 解析转磁力，保存位置持久化
- **传输中心**：本机下载（实时速度 / 剩余时间）与上传记录（进度 / 暂停继续取消重试）
- **文件上传**：小文件直传；大文件分片 + 断点续传；可整个文件夹递归上传，远端自动建目录
- **外部联动**：`mypad://` / `pan115://` / `magnet:` 与系统「分享到」直接提交云下载，剪贴板链接可自动或确认后提交
- **回收站**：列表 / 还原 / 彻底删除 / 清空
- **过滤规则**：条件树（文件名包含 / 排除 / 正则、大小、类型）+ 生效目录绑定，目录级就近继承
- **大屏适配**：手机单列 / 平板多列卡片流，宽屏内容居中防拉伸；手机底部导航 5 项，平板左侧导航栏

## 安装

从 [Releases](../../releases) 下载 `115OpenPad-v0.4.0.apk`（Android 8.0+）安装即可。

各版本的详细更新与修复见 [CHANGELOG.md](./CHANGELOG.md)。

## 构建

```bash
git clone https://github.com/zwyyydy/115OpenPad.git
cd 115OpenPad/115pad
./gradlew assembleDebug
```

需要 Android Studio 或命令行 Android SDK（platform 35 / build-tools 35.0.0）+ JDK 17。若 `local.properties` 里的 `sdk.dir` 与本机不符，请修改或删除后改设 `ANDROID_HOME`。

## 技术栈

Kotlin + Jetpack Compose (Material 3) + material3-window-size-class（平板自适应）、Retrofit + OkHttp + kotlinx.serialization、Coil（图片）、Media3 ExoPlayer（HLS 播放）、Room（媒体库索引）、DataStore（令牌与状态）、ZXing（二维码）、系统 DownloadManager（本机下载）。

## 已知限制

- **BT 任务**：`.torrent` 在本地解析出 info_hash 后以**磁力链**方式提交，官方 `add_task_bt` 要求先上传种子文件，故"按文件勾选下载"暂不可用
- **批量重命名**：「文本」方式替换所有出现位置；同目录已有任务在跑时，新建任务的预览可能不准
- **文件夹置顶**：只保存在本机，换设备不同步
- 4K / 原画播放需要 115 会员
- 开放平台接口有不公开的频控，请勿高频刷新（应用内已做列表缓存与节流）

## 凭据说明

应用支持两种登录方式：

1. **扫码授权**：需要自行在 [115 开放平台](https://pro.115.com/) 实名入驻并创建应用获取 AppID（client_id），填入 App 设置
2. **导入 Token**：无需 AppID，粘贴从 [OpenList Token 工具](https://oplist.org/) 获取的 access/refresh token 即可
