# 115 OpenPad

基于 [115 生活开放平台 API](https://www.yuque.com/115yun/open) 开发的第三方 115 网盘客户端，专为 **Android 平板与手机**设计（适配 1080p~4K 大尺寸屏幕）。


## 功能

- **登录**：扫码授权 / 免 AppID 导入 Token（access/refresh token 自动续期）
- **文件浏览**：列表 / 网格双视图、分类筛选、星标、搜索、面包屑导航、多选批量操作（移动 / 复制 / 重命名 / 星标 / 删除 / 下载，可一键全选）
  - 文件夹置顶：把常用文件夹在本目录内固定排到最前（长按多选 → 底部图钉按钮，可一次置顶多个），置顶项带图钉角标与淡蓝底。115 开放平台无置顶接口，故置顶只保存在本机、换设备不同步
  - 按目录记忆滚动位置：返回上级回到原处，进入内容更短的子目录也不再顶掉上级的位置
  - 目录列表本地缓存：60 秒内来回进出目录零请求，过期则先出缓存再静默刷新，降低接口频控压力
  - 文本预览：txt / py / md / js 等点开即预览，大文件按行分页，顶栏可切换编码
- **批量重命名**：查找替换（七种选段方式，可叠加多规则）、插入内容、自动编号（阿拉伯 / 中文大小写 / 英文字母）、手动编辑（粘贴多行自动向下填充），带「原名 → 新名」逐行预览
  - 执行走后台队列：顺序执行、限速可调、可暂停 / 取消 / 重试失败项；**关页面、退出应用都不中断**，下次打开接着跑；左侧导航「重命名」页看进度，也可直接选云盘目录建任务
- **图片浏览**：大图画廊（左右翻页、渐进式加载、相邻页预取、双击 / 捏合缩放、下拉关闭）
  - 超大图（>10MB）落盘后用 `BitmapRegionDecoder` 分块解码，整张原图不进内存，一亿像素图也不会 OOM
  - 放大后右下角浮出半透明鸟瞰位置图，长图 / 巨图不再迷失
- **视频播放器**（Media3 ExoPlayer）
  - HLS 流式播放 + 本地缓存（上限可调，回退进度零等待）
  - 手势：双击快进/快退、左右滑调亮度/音量、横滑非线性动态灵敏度快进（幂函数曲线：微调区 1~5s 精度、加速区滑满整屏跨越最大跨度）
  - 画面 90° 旋转（0°/90°/180°/270°，TextureView 等比渲染，竖屏片不形变）
  - HDR 片源转 SDR 输出（API 31+，避免泛白成灰雾）；软解 / 硬解就地切换（控制排最右侧，切完位置与档位不变）
  - 截图（左侧锁屏键上方）：抓当前画面存相册 `Pictures/115OpenPad/`，带字幕、跟随画面旋转，VR 下截的是反投影后的所见画面
  - **VR 观看**：180°/360° 立体素材实时反投影为平面；竖屏可选视窗档位（满屏 / 3:4 / 1:1）压掉垂直方向的边缘拉伸；进片 / 切集 / 换模式时视角自动归位（默认状态即复位状态）
  - **本地文件与外部唤起**：已下载的视频点一下用应用内播放器打开（长按交给其他应用）；其他应用「打开 / 分享视频」也能唤起本应用
  - 播放模式：顺序播放 / 单片循环 / 随机播放（剩余未播条目随机）；画面 0.5x~4x 长按倍速
  - 在线字幕搜索（按时长接近度排序）、字幕字号与位置可调
  - 播放列表抽屉（左滑删除源文件）、屏幕锁、多音轨、清晰度切换（含「原盘」直链）、缓冲中动效、右上角状态栏（时钟/电量/网速/画质规格）
- **云下载**：磁力链 / 电驴 / HTTP(S) / FTP 离线下载，.torrent 文件解析转磁力，保存位置持久化，任务状态实时刷新
- **传输中心**：本机下载（系统 DownloadManager 任务，带实时速度 / 剩余时间）与上传记录（传到哪个目录、大小、成败 / 秒传、进度 / 暂停继续取消重试）
- **外部联动**：支持 `mypad://download?url=…`、`pan115://…`、`magnet:` 及系统「分享到」，外部 App 唤起直接提交云下载；剪贴板链接可自动或确认后提交
- **回收站**：列表 / 还原 / 彻底删除 / 清空
- **文件上传**：小文件直接传；大文件分片上传 + **断点续传**（中断 / 暂停后接着传）；可选整个文件夹递归上传，远端自动建目录
- **过滤规则**：条件树（文件名包含/排除/正则、大小、类型）+ 生效目录绑定，目录级就近继承
- **大屏适配**：手机单列 / 平板多列卡片流，宽屏内容居中防拉伸

## 安装

从 [Releases](../../releases) 下载 `115OpenPad-v0.3.0.apk`（Android 8.0+）安装即可。

## 构建

```bash
git clone https://github.com/zwyyydy/115OpenPad.git
cd 115OpenPad/115pad
./gradlew assembleDebug
```

需要 Android Studio 或命令行 Android SDK（platform 35 / build-tools 35.0.0）+ JDK 17。若 `local.properties` 里的 `sdk.dir` 与本机不符，请修改或删除后改设 `ANDROID_HOME`。

## 技术栈

Kotlin + Jetpack Compose (Material 3) + material3-window-size-class（平板自适应）、Retrofit + OkHttp + kotlinx.serialization、Coil（图片）、Media3 ExoPlayer（HLS 播放）、DataStore（令牌与状态）、ZXing（二维码）、系统 DownloadManager（本机下载）。

## 已知限制

- **BT 任务**：`.torrent` 在本地解析出 info_hash 后以**磁力链**方式提交。官方的 `add_task_bt` 要求先把种子文件上传到 115，因此"按文件勾选下载"暂不可用；冷门资源若 DHT 拿不到元数据，会一直停在"分配中"
- **批量重命名**：「文本」方式是替换所有出现位置；同目录已有任务在跑时，新建任务的预览可能不准
- **文件夹置顶**：只保存在本机，换设备不同步（115 开放平台无置顶接口）
- **底部导航**：手机下现有 7 项偏挤（平板是左侧导航栏，无影响）
- 4K / 原画播放需要 115 会员
- 开放平台接口有不公开的频控，请勿高频刷新（应用内已做列表缓存与节流，但别手动狂点）

## 凭据说明

应用支持两种登录方式：

1. **扫码授权**：需要自行在 [115 开放平台](https://pro.115.com/) 实名入驻并创建应用获取 AppID（client_id），填入 App 设置
2. **导入 Token**：无需 AppID，粘贴从 [OpenList Token 工具](https://oplist.org/) 获取的 access/refresh token 即可
